# ReviewLens — (쉬운 설명서)

> 헷갈릴 때 이 파일만 보면 됩니다. 전문용어 없이 큰 그림만 정리했어요.

---

## 🟢 한 줄 요약

**쇼핑 리뷰를 AI가 대신 읽고 → 분석 + 추천 + 질문답변 + 마케팅 자동화(광고카피·답글)까지 해주는 도구.**
> ML부터 화면(Vue)·배포까지 **혼자 풀스택**으로 만든 **광고·마케팅용** 포트폴리오.

---

## 🖥️ 화면 미리보기

![분석 대시보드](reviewlens/docs/img/dashboard.png)

> 화장품 목업이 아니라, **실제 데모 리뷰(15상품·55리뷰)에서 뽑은 진짜 숫자**가 화면에 나옵니다. (왼쪽 위 70.3% = 전체 긍정 비율)

---

## 🤔 왜 만들었나 (문제)

- 상품 하나에 리뷰가 수백 개 → **다 못 읽음**
- 별점 4.5점만 봐서는 **"뭐가 좋고 뭐가 별로인지"** 모름
- "배송은 빠른데 포장이 별로"처럼 **항목별로** 알고 싶음

→ 그래서 리뷰를 **항목별로 쪼개서 분석**하고, 그걸 추천·질문답변에 써먹는 게 ReviewLens.

---

## 🧩 뭘 하나 (핵심 3가지 + 1)

| # | 기능 | 쉽게 말하면 |
|---|---|---|
| 1 | **속성별 감성 분석 (ABSA)** | 리뷰 한 줄을 "배송 👍 / 포장 👎 / 가격 👍"처럼 **항목별로 쪼개서** 좋고 나쁨 판정 |
| 2 | **추천** | "난 배송이랑 가격이 중요해" → 그에 맞는 상품 추천 + **왜 추천했는지 이유**까지 |
| 3 | **챗봇 (마케팅 어시스턴트)** | "이어폰 소리 어때?"는 물론 **"개선점이 뭐야?·강점은?·광고 카피 추천·재구매 의향은?"** 까지 리뷰 근거로 답함(17종 의도). 틀리면 고쳐주면 **기억함** |
| 4 | **AI 마케팅 자동화** | 리뷰 강점으로 **광고 문구 자동 생성**, 부정 리뷰엔 **답글 초안 자동 작성** (마케터 일을 AI가) |
| + | **마케팅 대시보드** | 위 결과를 **여러 탭(전략보드·리뷰분석·추천·마케팅·리포트…)** 으로 보는 웹 화면 |

**핵심 아이디어:** 1번에서 뽑은 "항목별 감성"을 **창고에 저장**해두고, 2·3·4번이 그 창고를 **공유해서 가져다 씀**. 따로 노는 게 아니라 하나로 연결됨.

```
리뷰 → [AI가 항목별 감성 분석] → [감성 창고] → 추천 / 챗봇 / 대시보드
```

---

## ✨ 이 프로젝트의 특별한 점 (면접에서 어필 포인트)

- 🖥️ **전부 내 컴퓨터(CPU)에서 돔** — 외부 AI 비용 0원, **인터넷 없어도 챗봇 작동**
- 🧠 **챗봇이 대화로 똑똑해짐** — 틀린 답을 고쳐주면 외부 메모리에 저장해 다음에 반영 (모델을 위험하게 재학습 안 함)
- 📊 **그냥 만든 게 아니라 "측정"함** — 정확도(F1) 같은 숫자로 성능을 증명. **실제 네이버 리뷰 3천 건으로도 검증**(별점과 87% 일치) — 데모 55리뷰가 다가 아님
- 🔒 **데이터 라이선스도 제대로 처리** — 받은 말뭉치는 GitHub에 안 올리고(.gitignore) 코드·결과만 공개

- [x] **챗봇 응답 빠르게** — 자주 묻는 질문(배송·추천·특정 상품)은 미리 요약을 만들어 두고 캐시 → **0.2초 즉답**(느린 CPU AI 호출을 실시간에서 거의 제거)
- [x] **데이터 보강** — 6개 상품·18리뷰 → 15개 상품·55리뷰로 확장 (정확도 F1 0.93)
- [x] **국립국어원 데이터로 "항목 추출" 학습** — 규칙 대신 AI가 항목을 찾도록 (micro-F1 0.66 > 베이스라인 0.62)
- [x] **마케팅 대시보드 UI** — 9개 탭(전략보드·리뷰분석·상품·고객·경쟁사·마케팅·알림·데이터·설정), **전부 실제 데이터로 표시**(목업 아님). **보고서 다운로드·인사이트 공유** 등 버튼도 실제 동작(클릭만 되고 안 되는 가짜 버튼 제거)
- [x] **AI 마케팅 자동화** — 리뷰 강점 → **광고 카피 자동 생성**, 부정 리뷰 → **답글 초안 자동 작성**
- [x] **챗봇 답변 확장** — 상품 비교·장단점·속성별·인사 등 (전부 리뷰 근거로) + 엉뚱한 질문은 안전하게 거절
- [x] **DB 선택형** — 기본 SQLite(파일 1개)·필요하면 Postgres(Docker)로 전환 (둘 다 다룰 줄 안다)
- [x] **실데이터 대규모 검증** — 실제 네이버 리뷰 3천 건에 ABSA 돌려 별점과 **87% 일치** 확인
- [x] **프런트엔드 Vue 전환** — 바닐라 HTML → **Vue 3 + Vite** SPA로 (화면·9탭·컴포넌트 분리, 모던 프런트)

## 🔨 현재 위치 (거의 다 됨)

핵심 기능(분석·추천·챗봇)과 **국립국어원 데이터로 항목 찾기 학습**, 그리고 **마케팅 대시보드 UI**까지 다 완성했어요.
- 예전: 단어 사전(규칙)으로 항목을 찾음 → 지금: 데이터로 학습해서 찾음 (사전에 없는 표현도 잡힘, micro-F1 0.66)
- 대시보드: 탭 여러 개 + 깔끔한 아이콘, 챗봇 탭은 실제로 동작

남은 건 욕심내면 **GPU로 더 정교하게 학습**하거나 **대시보드를 실데이터와 더 연결**하는 정도. 국립국어원 데이터는 라이선스 때문에 GitHub엔 안 올라가고 **내 컴퓨터에서만** 학습합니다(코드·결과만 공개).

## 📂 폴더 안에 뭐가 있나 (주요 파일만, 쉽게)

> 폴더만 봐도 역할이 보이게 **도메인별로 분리**했어요. (엔트리 3개는 root, 나머지는 폴더)

| 위치 | 하는 일 |
|---|---|
| `app.py` · `pipeline.py` · `eval.py` | 실행 진입점 — 웹서버 / 분석빌드 / 정확도측정 |
| `api/` | 웹 API 라우터 (board: 분석 · chat: 챗봇) |
| `store/` | 데이터 계층 (DB 어댑터·마이그레이션) |
| `absa/` | 리뷰 항목별 감성 분석 (규칙·LLM·학습 3방식 + 국립국어원 학습·검증) |
| `recommend/` | 추천 (감성 스코어러 + 협업필터링) |
| `chat/` | 챗봇 (의미검색 RAG + 답변 + 교정기억 + 평가) |
| `train/` | 감성 분류기 학습 (네이버 200k) |
| (별도) `frontend/` | 프런트엔드 — **Vue 3 + Vite** SPA (화면·9탭·컴포넌트) |
| `data/` · `db/` · `models/` | 샘플·정답·데모DB·학습 가중치 |
| `README.md` / `README1.md` / `README2.md` | 기술상세 / 쉬운버전(이 파일) / 개발일지 |

## ▶️ 실행 한 줄 요약

```bash
# 1) 프런트엔드 한 번 빌드 (Vue) — 이거 안 하면 화면이 안 떠요
cd frontend && npm install && npm run build && cd ..
# 2) 서버 실행
cd reviewlens && python -m uvicorn app:app     # → localhost:8000
```

(프런트를 고치며 작업할 땐: `cd frontend && npm run dev` → localhost:5173 / 챗봇 AI까지 쓰려면 Ollama로 `gemma3:4b`·`gemma4:12b` 받기)

## 🛠️ 안 될 때 (자주 묻는 것)

| 이런 일이 | 이렇게 |
|---|---|
| 챗봇이 답을 못 해요 | Ollama 앱이 켜져 있는지 확인 + `ollama pull gemma3:4b` |
| 첫 질문이 느려요(십수 초) | 처음 한 번 AI 모델을 불러오느라 그래요. 그 다음부턴 빨라져요 (CPU라 그렇고, GPU 있으면 빠름) |
| "프런트엔드 빌드가 없습니다" / 화면이 안 떠요 | `cd frontend && npm run build` 후 서버 재시작 (Vue 빌드 1회 필요) |
| 화면이 비어 있어요(데이터) | 새로고침 **Ctrl+Shift+R**. 그래도면 `python pipeline.py`로 데이터 다시 만들기 |
| 한글이 깨져요(윈도우) | 실행 전에 `set PYTHONUTF8=1` |
| 포트 8000을 쓰는 중이래요 | 기존 실행 창을 끄고 다시 실행 |

(더 자세한 표는 `README.md`의 "트러블슈팅" 참고)
