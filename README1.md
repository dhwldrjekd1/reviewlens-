## 🟢 한 줄 요약

**온라인 쇼핑 리뷰를 AI가 대신 읽고 → 장단점 분석 + 맞춤 추천 + 질문 답변까지 해주는 서비스.**

## 🖥️ 화면 미리보기

![분석 대시보드](reviewlens/docs/img/dashboard.png)

---

## 🤔 왜 만들었나 (문제)

- 상품 하나에 리뷰가 수백 개 → **다 못 읽음**
- 별점 4.5점만 봐서는 **"뭐가 좋고 뭐가 별로인지"** 모름
- "배송은 빠른데 포장이 별로"처럼 **항목별로** 알고 싶음

→ 그래서 리뷰를 **항목별로 쪼개서 분석**하고, 그걸 추천·질문답변에 써먹는 게 ReviewLens.

---

## 🧩 뭘 하나 (핵심 3가지 + 1)

| # | 기능 | 쉽게 말하면 |
|---|---|---|
| 1 | **속성별 감성 분석 (ABSA)** | 리뷰 한 줄을 "배송 👍 / 포장 👎 / 가격 👍"처럼 **항목별로 쪼개서** 좋고 나쁨 판정 |
| 2 | **추천** | "난 배송이랑 가격이 중요해" → 그에 맞는 상품 추천 + **왜 추천했는지 이유**까지 |
| 3 | **챗봇** | "이어폰 소리 어때?" 물으면 **리뷰를 근거로** 답해줌. 틀리면 고쳐주면 **기억함** |
| + | **마케팅 대시보드** | 위 결과를 **여러 탭(전략보드·리뷰분석·추천·챗봇·리포트…)** 으로 보는 웹 화면 |

**핵심 아이디어:** 1번에서 뽑은 "항목별 감성"을 **창고에 저장**해두고, 2·3·4번이 그 창고를 **공유해서 가져다 씀**. 따로 노는 게 아니라 하나로 연결됨.

```
리뷰 → [AI가 항목별 감성 분석] → [감성 창고] → 추천 / 챗봇 / 대시보드
```

---

## ✨ 이 프로젝트의 특별한 점 (면접에서 어필 포인트)

- 🖥️ **전부 내 컴퓨터(CPU)에서 돔** — 외부 AI 비용 0원, **인터넷 없어도 챗봇 작동**
- 🧠 **챗봇이 대화로 똑똑해짐** — 틀린 답을 고쳐주면 외부 메모리에 저장해 다음에 반영 (모델을 위험하게 재학습 안 함)
- 📊 **그냥 만든 게 아니라 "측정"함** — 정확도(F1) 같은 숫자로 성능을 증명
- 🔒 **데이터 라이선스도 제대로 처리** — 받은 말뭉치는 GitHub에 안 올리고(.gitignore) 코드·결과만 공개

- [x] **챗봇 응답 빠르게** — 자주 묻는 질문(배송·추천·특정 상품)은 미리 요약을 만들어 두고 캐시 → **0.2초 즉답**(느린 CPU AI 호출을 실시간에서 거의 제거)
- [x] **데이터 보강** — 6개 상품·18리뷰 → 15개 상품·55리뷰로 확장 (정확도 F1 0.93)
- [x] **국립국어원 데이터로 "항목 추출" 학습** — 규칙 대신 AI가 항목을 찾도록 (micro-F1 0.66 > 베이스라인 0.62)
- [x] **마케팅 대시보드 UI** — 9개 탭(전략보드·리뷰분석·상품·고객·경쟁사·마케팅·알림·데이터·설정), 깔끔한 라인 아이콘(Lucide), 챗봇은 실제 연결

## 🔨 현재 위치 (거의 다 됨)

핵심 기능(분석·추천·챗봇)과 **국립국어원 데이터로 항목 찾기 학습**, 그리고 **마케팅 대시보드 UI**까지 다 완성했어요.
- 예전: 단어 사전(규칙)으로 항목을 찾음 → 지금: 데이터로 학습해서 찾음 (사전에 없는 표현도 잡힘, micro-F1 0.66)
- 대시보드: 탭 여러 개 + 깔끔한 아이콘, 챗봇 탭은 실제로 동작

남은 건 욕심내면 **GPU로 더 정교하게 학습**하거나 **대시보드를 실데이터와 더 연결**하는 정도. 국립국어원 데이터는 라이선스 때문에 GitHub엔 안 올라가고 **내 컴퓨터에서만** 학습합니다(코드·결과만 공개).
